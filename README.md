# Генератор отчетов и презентаций для лабораторных работ

Этот скрипт на Python автоматизирует создание отчетов и презентаций (в формате `.qmd` для Quarto) на основе PDF-методички и скриншотов выполненных действий.

## Возможности
- Чтение методички (PDF) и извлечение текста.
- Автоматическое описание скриншотов с помощью нейросети Gemini.
- Генерация текста отчета (с ответами на контрольные вопросы).
- Генерация структуры и текста для презентации.
- Сборка готовых `.qmd` файлов с помощью шаблонов Jinja2.
