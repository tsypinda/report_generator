# Генератор отчетов и презентаций для лабораторных работ

Этот скрипт на Python автоматизирует рутину: он читает методичку (PDF), анализирует скриншоты ваших действий с помощью нейросетей и генерирует готовые файлы `.qmd` для отчетов и презентаций (собираются через Quarto).

## ✨ Возможности
- **Чтение PDF**: Автоматически извлекает текст, теорию и контрольные вопросы из методички.
- **Анализ скриншотов**: Распознает, что происходит на каждом скриншоте, и делает к ним краткие подписи.
- **Генерация отчета**: Пишет текст отчета (введение, теория, результаты, ответы на вопросы) и собирает `.qmd` файл.
- **Генерация презентации**: Создает структуру слайдов с краткими тезисами для защиты.
- **Защита от лимитов**: Умеет ждать и повторять запросы, если нейросеть выдает ошибку `429 Too Many Requests`.
- **Очистка**: Встроенный скрипт для быстрой очистки папки с данными перед новой лабой.

## 🚀 Установка

1. **Клонируйте репозиторий**:
   ```bash
   git clone https://github.com/tsypinda/report_generator.git
   cd report_generator
   ```

2. **Создайте виртуальное окружение и установите зависимости**:
   ```bash
   python -m venv venv
   
   # Для Linux/Mac:
   source venv/bin/activate
   # Для Windows:
   venv\Scripts\activate
   
   pip install -r requirements.txt
   ```

3. **Настройте конфигурацию**:
   Создайте в корне проекта файл `config.py` и заполните его:
   ```python
   # config.py
   
   # Настройки API (пример для Google AI Studio)
   API_KEY = "ВАШ_API_КЛЮЧ_ЗДЕСЬ"
   BASE_URL = "https://generativelanguage.googleapis.com/v1beta/openai/"
   MODEL_NAME = "gemini-3.5-flash-lite" # или другая доступная модель
   
   # Настройки прокси (если вы в России и используете VPN с локальным прокси)
   # Если прокси не нужен, закомментируйте эти строки и в main.py используйте обычный OpenAI()
   PROXY_URL = "socks5://ЛОГИН:ПАРОЛЬ@127.0.0.1:10808"
   
   # Ваши личные данные для титульного листа
   AUTHOR_NAME = "Иванов Иван Иванович"
   AUTHOR_GROUP = "студент группы НAAбд-03-23"
   AUTHOR_EMAIL = "ivanov@inbox.ru"
   ```

## 📂 Подготовка данных

Создайте папку `data` (если её нет) и поместите туда:
1. **`lab.pdf`** — методичку с заданием и вопросами.
2. **Папку `screenshots`** — со скриншотами ваших действий. Назовите их `рис1.png`, `рис2.png` и т.д. (Важно: сортировка идет по алфавиту, поэтому если картинок больше 9, используйте `01.png`, `02.png`... или `рис01.png`).

Структура должна выглядеть так:
```text
report_generator/
├── data/
│   ├── lab.pdf
│   ├── task.txt (создастся сам)
│   └── screenshots/
│       ├── рис1.png
│       └── рис2.png
├── template_pres.qmd
├── template_report.qmd
├── config.py
└── main.py
```

## 🏃‍♂️ Запуск

Убедитесь, что виртуальное окружение активировано, и запустите:
```bash
python main.py
```

Скрипт сделает всё сам: прочитает PDF, распараллелит обработку картинок (с защитой от лимитов), сгенерирует текст и соберет файлы `report.qmd` и `presentation.qmd` в папке `data/`.

## 🧹 Очистка перед новой лабой

Когда захотите сгенерировать отчет для следующей лабораторной, не удаляйте файлы вручную. Запустите:
```bash
python clean.py
```
Скрипт спросит подтверждение и удалит все PDF, скриншоты и сгенерированные файлы из папки `data`, оставив структуру папок готовой к работе.

## ⚠️ Важные нюансы

### Лимиты бесплатных тарифов
Бесплатные модели (например, Gemini) имеют лимит на количество запросов в минуту. Скрипт автоматически ждет и повторяет попытку, если получает ошибку `429`. Обработка 40+ картинок может занять несколько минут, это нормально.

### Проблемы с VPN на Linux
Если вы используете VPN (например, INCY) и Python не видит сеть, в `main.py` уже настроена поддержка SOCKS5-прокси. Вам нужно включить «SOCKS5 авторизацию» в VPN-клиенте, скопировать логин/пароль/порт и вписать их в `PROXY_URL` в `config.py`.

### Компиляция `.qmd`
Сам скрипт только генерирует файлы `.qmd`. Чтобы получить из них PDF или PPTX, используйте Quarto (команду `quarto render` или `make`, если у вас настроен Makefile).
